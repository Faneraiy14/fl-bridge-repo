# FL Bridge — релізи

Цей репозиторій містить **тільки зібраний `FLBridge.jar`**. Вихідного коду тут немає.

## Що це

FL Bridge — точка входу мод-лоадера FL Loader. Він підміняє звичайний запуск
Minecraft: піднімає власний class loader, підключає моди й лише потім віддає
керування грі.

Завантажувати вручну не потрібно — [FL Launcher](https://github.com/Faneraiy14/fl-launcher)
сам бере `FLBridge.jar` з останнього релізу, кладе його в `fl-bridge/` у своїй
папці й оновлює, коли виходить новіша версія.

## Версії

Тег релізу відповідає версії моста (наприклад `v3.0.3`). Лаунчер зберігає
встановлену версію у `version.txt` поруч із `.jar` і звіряє її з останнім релізом.
